# NerdProjects

Bienvenue sur **NerdProjects**, un espace regroupant différents projets informatiques, applications et expérimentations développés par Ylann.

Ce dépôt GitHub contient le code source du site NerdProjects ainsi que les différentes pages permettant d'accéder aux projets disponibles.

## Accéder au site

**Site web :** https://ylann33-code.github.io/projects/

---

## Les projets

### 1. NeuralMatch

NeuralMatch est un outil interactif permettant de calculer un pourcentage de compatibilité entre deux personnes à partir de certaines informations.

**Fonctionnalités :**
- Saisie des prénoms.
- Saisie des âges.
- Calcul d'un pourcentage de compatibilité.
- Affichage d'un résultat personnalisé.
- Interface animée et interactive.

**Identité visuelle :** thème bleu cyan, avec une ambiance technologique et futuriste.

### 2. PhotoCup

PhotoCup est un projet proposant une application Android ainsi qu'une version accessible directement depuis un navigateur.

Deux possibilités permettent d'accéder à PhotoCup :

**Application Android (APK)**

[ Télécharger PhotoCup.apk ](https://github.com/ylann33-code/projects/releases/download/App/PhotoCup.apk)

**Version web**

https://ylann33-code.github.io/photocup/

**Identité visuelle :** thème rose, avec des effets lumineux et une interface moderne.
